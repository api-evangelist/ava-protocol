# Ava Protocol

> Automate onchain actions with AI. Move, protect, and manage capital without giving up control.

Ava Protocol is an AI-powered onchain automation platform for Ethereum and L2s (Base, Soneium). Users create and run workflows through a chat interface or templates to automate actions like swaps, transfers, notifications, and contract execution — without giving up control of their assets. The platform focuses on automating capital movement, risk management, and execution across onchain environments.

## Core concepts

- **Workflows**: automation flows connecting triggers (scheduled time, price conditions, onchain events, manual) to actions (swap, transfer, contract call, notification).
- **AI agents**: assist users in building, editing, and managing workflows through natural language.
- **Smart wallets**: segmented accounts with scoped permissions so automations can move capital under guardrails the user defines.
- **Templates**: ready-made workflows for common use cases (DCA, stop-loss, payment splits, notifications).
- **Execution checkout**: a flow where users authorize automations non-custodially before execution.
